# FFXI-Addons

## autorun
Programmatically hold the numpad8 key down.

`//ar` toggles the key up and down.

*Useful to keep autorun active while chocobo digging.*

## digtracker

Chocobo Digging statistics tracker for FFXI. [Enhanced fork of DigTracker](https://github.com/benbou8231/peterjez_ffxi/tree/main/digtracker).
